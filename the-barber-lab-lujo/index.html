Ref. 04 · Tricología

Lo que nos hace un Lab, y no sólo una barbería.

El tratamiento empieza con una exfoliación del cuero cabelludo a base de algas. Después se aplica una ampolla formulada para tu caso concreto — no la misma para todo el mundo.

Veinticinco minutos. Se puede reservar solo o combinado con corte.
